# Prototipo página web — Liceo Lunita de Chía

Propuesta interactiva del sitio web institucional para el **Liceo Lunita de Chía** (Chía, Cundinamarca).

## Demo en línea

- **Vista previa:** https://jlpineda12.github.io/prototipo-pagina-web-liceo-lunita-de-chia/

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilación de producción

```bash
npm run build
npm run preview
```
